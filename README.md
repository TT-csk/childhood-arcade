# 🎮 童年游戏厅

**让家里的安卓电视，变成全家都能玩的复古游戏厅。**

当前版本：**1.0 正式版**。

通过电脑上的智能体完成安装，接上兼容手柄就能选游戏。部署完成后，游戏厅和游戏都保存在电视上，玩游戏时不需要电脑一直开着。

## 有什么、能做什么？

目前整理了 **179款游戏**，覆盖五个平台：

| 平台 | 代表游戏 |
| --- | --- |
| 红白机 | 超级玛丽、魂斗罗、松鼠大战 |
| 街机 | 吞食天地Ⅱ、拳皇97、拳皇98、合金弹头 |
| GBA | 宝可梦、牧场物语、恶魔城 |
| 世嘉 MD | 索尼克2、暴力摩托、雷霆力量Ⅳ |
| 超级任天堂 SFC | 星之卡比等 |

- **双人合作入口**：方便两个人找游戏，具体玩法以游戏支持情况为准。
- **收藏与最近玩过**：快速找到想玩的游戏。
- **整理首页**：调整游戏排列顺序。
- **存档与备份**：保存进度，按需要备份、恢复已保存数据。

## 需要准备什么？

- **电视或电视盒子**：Android 6.0或以上，并支持32位 ARM 应用（`armeabi-v7a`）。仅支持64位应用的系统不能安装当前 APK。
- **电脑与智能体**：智能体需要支持安装 Skill、访问本机文件和执行命令；只有网页聊天功能的工具无法直接部署。
- **Python 3.9+ 和官方 ADB**：用于运行部署工具、连接电视，可以先让智能体检查是否安装。
- **网络与手柄**：电脑和电视连接可互通的网络，通常用同一个家庭路由器；准备兼容手柄。

电视还需要足够的剩余存储空间，部署前会检查。详细要求见[安装指南](docs/安装指南.md)。

## 怎么安装？

### 1．让智能体安装 Skill

把这段话复制给电脑上的智能体：

> 请按你支持的 Skill 安装方式，安装这个仓库中的童年游戏厅部署技能：
> 仓库：https://github.com/TT-csk/childhood-arcade
> 技能路径：skills/childhood-arcade-tv
> 如果你不支持安装 Skill 或执行本机命令，请先告诉我。

安装方法因智能体而异，按工具要求重新开启会话或加载技能。

### 2．告诉智能体安装到哪台电视

打开电视，查看网络设置里的 IPv4 地址，然后发送：

> 使用 childhood-arcade-tv，帮我把童年游戏厅安装到电视上，电视 IP 是：这里填写电视地址。

首次需要在电视上开启 **ADB 调试**，并用遥控器确认允许电脑连接。找不到入口时，告诉智能体电视品牌和型号，让它指导你操作。

智能体会下载游戏厅和资源、检查文件并执行部署。对应 GitHub 版本发布后，自动下载才会生效。

### 3．打开游戏厅

部署完成后，在电视应用列表打开 **「童年游戏厅」**，用手柄选择游戏。建议先试玩一款，确认画面、声音、操作和存档正常。

## 怎么更新？

电脑能够连接电视时，对智能体说：

> 帮我更新电视上的童年游戏厅。

工具会检查版本，并在支持的更新流程中先备份已保存进度。遇到签名冲突、备份失败或设备身份改变时会停止，不会自动卸载或清除存档。详情见[存档与更新指南](docs/存档与更新指南.md)。

## 当前适配情况

已有指定小米电视及双手柄的使用记录；本次发布后的完整流程将用新 Windows 电脑继续验收。不同智能体、电视和手柄的兼容情况需要分别确认，不能保证全部设备都能使用。游戏运行效果也受设备和场景影响。
