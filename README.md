# 🎮 童年游戏厅 v2.1

让家里的安卓电视，变成全家都能玩的复古游戏厅。

## v2.1 更新内容

### 手柄操作更好上手

- 增加首次按键引导，覆盖 A、B、X、Y、开始、投币／选择与暂停键；补充通用编号按键的识别与映射。
- 简化改键和连发设置：自行选择实体触发键、重复的游戏按键及连发速度，支持按游戏、按玩家分别保存。
- 修复连发设置中 B 键误返回、开始键保存冲突等问题，设置可使用手柄完成。
- 明确显示 1P／2P，改善玩家绑定、断线提醒和重连恢复，提供输入检测、摇杆校准与死区调整。
- 底部增加方向、A 确认、B 返回等按键提示，更新大厅标志及电视安装图标。

### 在大厅内导入 U 盘资源包

- 扫描已连接 U 盘及可访问目录，展示可选标准 ZIP 资源包，无需额外安装文件管理器或电脑编辑器。
- 导入前检查资源包格式、可用空间和重复资源，导入时显示进度，失败时说明原因。
- 资源复制到电视后运行，成功导入后可拔出 U 盘；再次导入时复用已校验的相同资源。
- 不同电视的目录访问权限存在差异，无法直接读取时按大厅提示授权。普通游戏 ZIP 不一定符合资源包格式。

### 启动、游戏库和故障提示

- 优化大厅启动和大游戏库浏览，游戏列表分页显示，搜索仍覆盖完整游戏库。
- 完善保存失败处理与存档恢复校验，减少异常状态造成的操作阻塞。
- 增加游戏启动阶段、资源缺失、启动超时和运行异常提示，以及本机诊断记录，方便定位问题。

本版保留现有全屏与画面显示方式，继续使用 v2.0 游戏资源包。上述改动已完成电脑检查及一台小米电视的主要流程测试；原反馈用户的白屏和手柄问题尚未在其设备复测，不能保证所有设备表现一致。

## 下载和安装

支持 Android 5.0（API 21）及以上的 ARM 电视或盒子：

- [下载 32 位游戏厅 APK](https://github.com/TT-csk/childhood-arcade/releases/download/v2.1.0/childhood-arcade-2.1.0-arm32.apk)
- [下载 64 位游戏厅 APK](https://github.com/TT-csk/childhood-arcade/releases/download/v2.1.0/childhood-arcade-2.1.0-arm64.apk)
- [下载游戏资源包 v2.0（本版沿用）](https://github.com/TT-csk/childhood-arcade/releases/download/v2.0.0/childhood-arcade-games-2.0.0.zip)
- [查看版本附件及文件校验值](https://github.com/TT-csk/childhood-arcade/releases/tag/v2.1.0)

**已有用户请沿用原来的架构覆盖升级。** 已安装 1.0 的用户优先选择 32 位版；部分旧即时存档不能直接由 64 位核心读取。两版使用相同包名，不要卸载旧版来解决更新或签名问题，以免删除本机数据。

更新前请导出并保留备份。正式 2.0 用户可在大厅更新入口检查新版，下载后仍需完成 Android 系统安装确认；若访问 GitHub 失败，可下载对应架构 APK 手动覆盖安装。2.0→2.1 大厅内升级的完整电视验收正在安排，完成后补充结果。

游戏资源包与大厅分开下载；已有完整资源无需因为升级大厅而重新导入。首次导入时，将标准资源包 ZIP 放入 U 盘，进入大厅资源入口扫描、选择并确认导入，等待成功后再拔出 U 盘。电视需有足够的内部存储空间。
