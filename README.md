# 🎮 童年游戏厅 v2.0

让家里的安卓电视，变成全家都能玩的复古游戏厅。

## 下载和安装

游戏厅支持 Android 5.0（API 21）及以上，安装包分为两种：

- **32 位版**：已经安装 1.0 的用户使用此版本覆盖升级，保留原有 32 位游戏核心。
- **64 位版**：适用于系统支持 64 位 ARM 应用的电视或盒子。已有 1.0 用户请优先使用 32 位升级版；部分旧即时存档不能直接由 64 位核心读取。

正式下载（发布后生效）：

- [下载 32 位游戏厅 APK](https://github.com/TT-csk/childhood-arcade/releases/download/v2.0.0/childhood-arcade-2.0.0-arm32.apk)
- [下载 64 位游戏厅 APK](https://github.com/TT-csk/childhood-arcade/releases/download/v2.0.0/childhood-arcade-2.0.0-arm64.apk)
- [下载游戏资源包 v2.0](https://github.com/TT-csk/childhood-arcade/releases/download/v2.0.0/childhood-arcade-games-2.0.0.zip)
- [查看版本附件及文件校验值](https://github.com/TT-csk/childhood-arcade/releases/tag/v2.0.0)

两版使用同一个应用名称和包名，请按设备及升级情况选择一个。安装前建议通过旧版设置备份存档、收藏和配置；打开 APK 后，在系统安装界面确认更新。不要卸载旧版来解决签名错误，以免删除本机数据。

游戏资源包与大厅分开下载：安装大厅后，在游戏厅的资源入口选择资源包导入。电视需要有足够存储空间；手柄、画面和声音效果因设备而异。

## v2.0 有什么

- 重新整理大厅、设置、资源和更新入口。
- 可调整手柄操作、画面与声音，备份和恢复保存的数据。
- 同一游戏可以选择原版与不同版本，各版本分别保存进度。
- 大厅和游戏资源包分别更新。
