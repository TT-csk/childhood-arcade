# 部署与验收

## 智能体调用

在 Skill 目录运行：

```sh
python3 scripts/setup_release.py --repo OWNER/REPO --serial 电视IP
```

Windows 按实际 Python 安装使用 `python` 或 `py -3`。版本、资源名、传输协议与 SHA-256 固定在 `assets/release.json`。只能使用用户指定的真实仓库；没有发布版本不能假装下载成功。省略 serial 只下载和准备文件，不连接设备。

本地验收可运行：

```sh
python3 scripts/tv.py configure --apk /绝对路径/app.apk --sha256 APK的SHA256 --game-pack-manifest /绝对路径/game-pack/manifest.json --transport provider
python3 scripts/tv.py deploy --serial 电视IP
```

首次必须在电视确认调试授权。新安装会校验资源、检查新鲜页面状态并截图；页面成功不代表所有游戏和手柄通过。用户还需试听、实际操作并验证存档。

## 备份与恢复

```sh
python3 scripts/tv.py backup --serial 电视IP --output /绝对路径/backup.json
python3 scripts/tv.py restore --serial 电视IP --input /绝对路径/backup.zip
```

provider 模式生成 ZIP，实际路径以输出报告为准（即使 output 写 .json 也会改为 .zip）。恢复前核对设备身份和备份来源；恢复过程会覆盖备份包含的同名已保存状态，其他游戏资源保留。命令会停止游戏厅，不包含停止前未保存的进度。恢复失败会尝试回滚，进程重启时通过日志恢复中断操作。

## 升级注意事项

1.0.0 使用仓库外独立发行密钥，和旧本地调试包不同；遇到签名冲突不可卸载重试。测试电视保持原版，优先使用新设备。自动安装不会绕过系统授权或扫描电视。

当前验证：本地 Python 自动测试；隔离 Android 30 模拟器上的无原生游戏库传输测试包完成52项资源验证、备份恢复及中断回滚。完整游戏 APK 的32位原生内核运行、新 Windows 电脑和 Android 6 真机尚待最终验收。
