# 文件校验、权限与结构

## 文件校验

部署工具用 SHA-256 核对 APK、资源 ZIP 和每个资源文件。版本清单 assets/release.json 固定版本、附件名和哈希；下载或内容不符时停止。解压还会检查路径、重复文件和大小限制，校验通过后才写入配置。

版本附件的 SHA256SUMS.txt 用于核对文件完整性。完整性校验不能单独证明来源可信、内容安全或设备兼容。

## 部署权限

首次电视授权允许电脑使用 ADB。APK 和 WebView 调试关闭，正式传输接口由 android.permission.DUMP 和调用 UID 双重限制，资源按照 APK 内白名单验证，不提供任意文件路径操作和额外网络服务。

页面检查读取应用近期上报的实际页面状态，不把进程存在当作页面成功。installed_unverified 表示尚未确认页面；页面确认也不代表游戏性能、声音或实体手柄通过。

## 项目结构

- skills/：电脑端智能体部署 Skill。
- source/：应用代码审阅副本及第三方说明。
- docs/：安装、原理、更新、测试和构建说明。
- Release 附件：APK、游戏 ZIP、Skill ZIP、应用构建输入 ZIP、SHA256SUMS.txt。

应用构建输入包含预编译原生库及依赖，能够重建应用不表示所有内核都已从源码重编译。组件分别适用 source/LICENSE、source/licenses 和 source/THIRD_PARTY_NOTICES.md 中的许可。
