# v2.1.0 更新说明

本版重点优化手柄设置与 U 盘资源导入，并完善启动、游戏库浏览、保存失败处理和故障诊断。

- 手柄：ABXY 首次引导、通用编号按键映射、独立 1P/2P 配置、断线重连、输入检测、校准与死区。
- 连发：自由选择实体触发键和游戏按键，分游戏／玩家保存；修复 B 键误返回和开始键保存冲突，可使用手柄完成设置。
- U 盘：大厅扫描标准 ZIP，检查格式、空间及重复资源，显示进度和失败原因；复制到电视后可拔盘运行。
- 大厅：启动优化、游戏列表分页、完整库搜索；方向及 A/B 按键提示、新手柄标志和安装图标。
- 稳定性：完善存档校验及失败处理；增加启动阶段、超时与本机诊断记录。

继续沿用 v2.0 资源包，画面与全屏方式保持现有设置。已有用户请先备份、选择原有架构 APK 覆盖更新，勿卸载。

验证范围：电脑检查及小米 MiTV4-ANSM0（Android 6.0.1，ARM32）主要流程。原反馈用户设备、所有电视和全部异常路径尚未覆盖。正式 2.0→2.1 大厅内升级在发布后单独验收，不能以 ADB 覆盖代替。

安装包版本 2.1.0 / versionCode 220，沿用正式 2.0 包名与签名。附件 SHA256SUMS.txt 提供校验值。
