# 安装指南

## 设备和工具

电视或盒子需要 Android 6.0/API23 起，并支持 armeabi-v7a。电视处理器是64位，不代表系统一定支持32位应用，也不代表不支持；要检查实际 ABI 列表。

电脑上的智能体必须能加载 Skill、访问本地文件并执行命令。不同产品的技能安装目录和调用方式不同，需要遵循所用工具的说明；不能假设所有聊天工具都能安装。本项目脚本需要 Python 3.9+ 和 Google 官方 Android Platform Tools（ADB）。Windows 可使用实际安装的 python 或 py -3，其他系统通常用 python3。

## 空间

APK 下载约22MB，资源 ZIP 约375MB，资源解压后约495MB。系统安装展开、传输临时文件与存档还会占空间，下载大小不等于电视最终占用。部署脚本会检查当前剩余空间；实际峰值尚需在不同电视记录，不能用电视标称容量替代检查。运行内存 RAM 与存储空间是两回事；2GB RAM 是已有电视使用记录，不是确认的最低值。

## 电视连接

电脑和电视必须网络互通，建议同一个家庭路由器。电视开启 ADB 调试，提供当前 IPv4 地址，首次用遥控器允许电脑连接。菜单因品牌和固件不同，按实际界面寻找。

连接失败时先核对电视是否开机、IP是否变化、ADB是否启用，以及路由器是否隔离设备。电脑开 VPN 时检查其局域网访问设置；不同地点分别开启普通 VPN 不代表设备能够互通。不要将 ADB 暴露到公网。

## 常见问题

- 智能体不能执行命令：需要使用具备本机操作能力的环境。
- 下载404：确认仓库公开可访问、版本标签和附件已经发布、名称与技能内清单一致。私有附件的认证下载尚未接入。
- 无法安装：检查系统、ABI、剩余空间、安装限制和签名冲突。
- 手柄无反应：检查连接、电视是否识别设备，再检查按键映射；蓝牙设备先配对。不能保证所有手柄直插可用。
- 游戏卡顿：记录具体游戏、画面/声音/按键的表现和设备型号，再做针对性检查。
