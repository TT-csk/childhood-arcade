# 安装指南

## 选择版本

Android 5.0 及以上设备，根据系统支持的 ARM 架构选择安装包。已有 1.0 的用户请选择 32 位版覆盖安装；64 位版只适用于支持 64 位 ARM 的系统。已有 32 位即时存档不保证可由 64 位核心读取。

## 覆盖升级

1. 先在旧版内备份游戏进度、收藏和设置，并妥善保存备份文件。
2. 将 32 位 APK 复制到电视可读取的位置，用文件管理器打开。
3. 查看电视系统的更新确认界面并确认。签名冲突时停止，不要卸载旧版或清除数据。
4. 打开新版，检查收藏、设置以及需要继续的存档。
5. 游戏资源包需另行下载并从大厅的资源管理入口导入。

电视的安装界面和安装权限设置因型号而异。遇到空间不足或安装失败，先保留原有数据并检查提示。
