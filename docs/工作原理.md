# 游戏厅是怎么工作的？

Skill、APK 和资源包有不同分工：

- **Skill** 是电脑上智能体的操作说明和工具，负责下载、检查、安装和更新。
- **APK** 是电视上的游戏厅程序，负责显示大厅、处理手柄输入、调用模拟器和管理存档。
- **资源包** 保存游戏文件，部署时由工具传到电视。

用户不需要逐个安装游戏。部署完成后，打开电视上的大厅就能看到已准备好的游戏。游戏厅在电视本地运行，不需要电脑持续开机。

不同平台使用相应的模拟器内核。选择游戏后，大厅按平台调用内核，接收手柄输入，输出画面和声音；用户不需要分别打开多个模拟器。

目录包含179款游戏、190个游戏版本。同一款作品可能存在多个版本，因此两个数量不同。

电脑和电视各自保存数据，游戏目录一致不表示存档自动同步。不同内核或不同版本的即时存档也不保证兼容。
