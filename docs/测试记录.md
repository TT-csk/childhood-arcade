# 测试范围和问题反馈

已完成本机部署脚本测试、独立输入目录重建应用、签名和关闭调试状态检查。在隔离 Android30 ARM64 模拟器中，使用去掉原生游戏库的传输专用包，验证52项资源传输、备份恢复与恢复中断回滚。传输测试不能代替完整游戏在电视上的运行测试。

已有 MiTV4-ANSM0、Android6、2GB RAM 及两只 SHANWAN 手柄的使用记录。本次发布构建的 Windows 从零部署和32位 Android 电视完整游戏体验仍需验收。不同智能体的技能发现、命令执行及系统工具调用需要分别确认。

反馈时提供电视品牌型号、Android版本、电脑系统、智能体名称、游戏名称、操作步骤和具体错误。区分无法连接、安装失败、声音断续、画面卡顿和按键无反应。分享日志前遮住个人路径、设备标识、密码、令牌等信息，不公开发行密钥和存档备份。
