# 从独立构建输入重建应用

Release 的 `childhood-arcade-build-inputs-1.0.0.zip` 包含应用源代码、必要素材和预编译原生内核/JNA、所收集的第三方源码归档。它支持重建应用 APK；不声称所有原生内核已经由这些归档从零重建或达到逐字节可复现。PicoDrive 的运行相关子模块归档按原提交记录收集；dr_libs 的外部测试依赖不参与应用构建。

准备 JDK 17、Android SDK build-tools（aapt2、d8、zipalign、apksigner）及 Android 35 的 android.jar。命令必须提供本机真实路径：

```sh
python3 scripts/build-production.py --jdk JDK目录 --tools BUILD_TOOLS目录 --android-jar android.jar路径 --signing-config 仓库外签名配置JSON
```

签名配置包含 keystore、alias、password 三个字段，属于机密，不放入仓库、Release、截图或日志。密码只通过子进程环境传入签名工具。用自己的密钥构建的版本不能覆盖原发行签名版本。

此构建流程已在开发 Mac 上从独立输入目录成功运行，产物的 classes.dex、Manifest、资源白名单与制作目录构建一致；签名和 ZIP 元数据可能导致 APK 总哈希变化。Windows 构建流程尚未验证；Windows 本轮目标为电脑端部署，不要求用户构建 APK。
