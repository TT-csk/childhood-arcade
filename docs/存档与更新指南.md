# 存档、备份和更新

存档保存在当前设备，电脑与电视不会自动同步。不同内核和游戏版本的即时状态不保证互通。

备份包括已保存设置、收藏等数据、即时存档、电池存档和 NES SRAM。它不包含 ROM，也不包含尚未保存的运行中进度。备份和恢复会先停止应用，请先在游戏里保存。

恢复会覆盖备份包含的同名已保存状态，恢复后重新打开游戏检查结果。脚本检查路径和 ZIP 完整性；失败尝试回滚，进程重新启动时处理恢复事务日志。实际命令见[部署流程](部署流程.md)。

覆盖更新需要相同发行签名。遇到签名冲突、备份失败或电视身份改变时，工具停止并保留已有数据，不自动卸载。使用自行签名的 APK 不能直接覆盖其他发行签名；发行密钥需要私下保管，丢失会影响后续更新。
